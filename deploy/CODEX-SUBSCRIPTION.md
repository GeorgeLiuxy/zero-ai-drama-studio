# Codex 订阅供应商

本机源码部署新增 `Codex（ChatGPT 订阅）` 供应商。文本通过本地 Codex App Server 返回结构化结果；图片通过内置图片工具返回的完成事件获取文件。内嵌创作 Agent 也支持 Codex Python SDK，在设置 → Agent 中独立选择。

## 使用

1. 在运行 ArcReel 后端的同一系统账户下安装 Codex CLI，并执行 `codex login`，选择 ChatGPT 登录。
2. 在 ArcReel 设置 → 供应商 → Codex 中连接或刷新。此操作只读取账户和模型信息，不发起模型生成。
3. 在模型选择中配置 Codex 文本模型；图片验证通过后可以选择 GPT Image 2。
4. 已有项目的模型覆盖优先于全局配置；项目内配置过的简单/复杂文本、文生图/图生图需要分别检查。

Codex 需要的登录状态由 CLI 管理，不向 ArcReel 数据库或前端复制登录令牌。页面断开只停用 ArcReel 供应商，不退出共享 Codex 账户。后端在每次生成前再次检查 ChatGPT 登录身份，不接受 API key 登录，不回落到付费供应商。

可选环境变量：

- `ARCREEL_CODEX_BIN`：Codex 原生可执行文件绝对路径。Windows 可指定 npm 包内的 `codex.exe`；默认自动定位现有安装。
- `ARCREEL_CODEX_TIMEOUT_SECONDS`：生成超时，默认 600 秒，限制在 30–3600 秒。

## 图片能力验证

图片候选只在验证通过后出现。登录账户或 CLI 版本变化会清除验证状态。以下命令不调用模型，只检查连接：

```powershell
.venv/Scripts/python.exe scripts/verify_codex_subscription.py
```

需要重新验证时显式执行以下命令，会消耗一次订阅图片生成额度；成功后刷新供应商页面：

```powershell
.venv/Scripts/python.exe scripts/verify_codex_subscription.py --image
```

本次本机验证使用 Codex CLI 0.133.0、ChatGPT Pro：一次结构化文本返回通过；一次参考图编辑生成通过并验证真实 PNG。文本会话报告 2,877 tokens；图片会话报告 5,021 tokens。该回报不能换算为准确的订阅额度百分比或独立的图片计费量。

## 任务与用量

文本、图片共用一个串行执行通道。每次调用使用隔离临时会话，避免带入其他项目历史。生成失败不在 ArcReel 适配层自动重试；需要用户检查后重新提交。取消会传给 Codex，运行进程完成清理前不会释放下一个生成名额。进程重启后的未完成任务沿用原有失败处理，不自动重复生成。

图片文件经过可读性检查后交给现有临时文件、版本和项目资产提交流程。宽高比及尺寸作为生成要求传入，模型实际输出尺寸不保证精确相等；当前接口不承诺固定随机种子。

用量账单中的 0 API 调用费用表示没有额外按 API 单价计费，不表示订阅无限或免费。CLI 返回的可获得 token 用量会记录；没有返回的图像用量不会猜测。详细订阅剩余额度仍以 Codex 自身显示为准。

视频、音频继续使用单独配置的供应商。AutoDL 视频服务需要另外部署和配置。

## 内嵌 Codex Agent

新建项目与对话的流程修复及当前验收范围见 [Codex 新创作流程检查与修复](CODEX-NEW-WORKFLOW.md)。下方早期接通记录属于历史验证，不代表整集创作流程已通过真实模型验收。

完成供应商连接后，打开设置 → Agent，启用 Codex Agent，选择当前账户可用的模型与推理强度并保存。刷新连接只读取账户及模型信息，不发起生成。此项配置独立于简单/复杂文本、图片、视频等模型槽位。

Agent 使用官方 `openai-codex` Python SDK（当前锁定 0.147.0 及其同版本自带运行器），通过本机 ChatGPT 登录执行对话。现有文本/图片供应商继续使用 `ARCREEL_CODEX_BIN` 指定或自动找到的 CLI，不因 Agent SDK 升级而改变已验证的图片运行器。

会话复用 38 个项目业务工具，并补充 3 个项目/用户记忆工具；支持源文读取、资产清单、分集规划、剧本创建/审查以及媒体任务提交与查询，需要补充信息时仍使用页面上的问题卡片。媒体生成沿用各自配置的供应商，启用 Codex Agent 本身不提供未配置的视频或音频模型。旧 Claude Agent 的任意 shell 命令、文件读写和子智能体不随此适配迁移；Codex 通过项目业务工具完成创作。

新会话采用保存的引擎、模型及推理强度。已有会话保留自己的运行方式；Codex 对话 ID、模型与完成轮次随 transcript 存入 ArcReel 的 SessionStore，重启后恢复原线程，改写用户消息时从对应历史轮次分支。旧 Claude 历史继续由 Claude SDK 读取。此实现要求开启 SessionStore，不能在关闭持久化时创建 Codex Agent 会话。

同一会话按顺序执行轮次；等待问题答复时也支持停止。超时会关闭运行器并结束当前轮次，不在应用层自动重试或切换到 API 密钥供应商。`ARCREEL_CODEX_AGENT_TIMEOUT_SECONDS` 可设置单轮超时，默认 1800 秒。账户登录信息仍由 Codex 管理，不复制到账户配置数据库。

本机 Agent 的 SDK 传输使用独立的 `arcreel_openai_http` 配置，强制 ChatGPT 认证并直连官方订阅端点，关闭 WebSocket，避免当前网络下先重连五次再退回 HTTP。此配置只应用于启动的 SDK 进程，不写共享 Codex 配置。继承的外部 MCP 仅在该线程中禁用，无关 skills 的自动指令也关闭。

Agent 按线程累计用量相对本轮起点的差值记账，覆盖工具调用之间的多次推理；冷恢复从首个用量事件推算起点，重复通知不会重复累计。API 金额仍为 0，订阅额度实际消耗以 Codex 为准。
