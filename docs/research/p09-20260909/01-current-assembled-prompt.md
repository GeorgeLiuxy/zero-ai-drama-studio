# 字段写作指引

把源文拆为有序分镜，逐条产出结构化分镜内容。当前正在生成第 2 集。

## 跨镜状态与空间连续性
为每个分镜填写 continuity；先确定同一时空段落，再设计各镜头，宫格数量不决定剧情分段。
start_state 是首帧，action_beats 是本镜实际发生的动作，end_state 是动作结果。
相邻同场景镜头的物理状态按上一镜 end_state 承接；未变化的事实沿用同一 subject/attribute/value。
只记录影响叙事的姿态、世界位置、朝向、持物与固定布置，无法确定的事实填 unknown 并说明 uncertainties。
world_position/layout 以门、床、墙等固定锚点为基准；screen_position 仅表示当前画面左右，二者不能混用。
camera_side 以同一条场景轴线命名。同场景可换景别或正反打，但无依据跨轴或镜像场景要提出问题。
连续动作使用 continuous_action；正常剪辑使用 same_scene_cut，不把下一镜首帧一律当成本镜尾帧。
换场景/跳时分别使用 scene_change/time_jump，解释 transition_reason；新场景同步 segment_break。
例如「蹲在床旁→站稳→走到床边→坐下」应按可用时长安排动作，不把坐下结果提前画进起身镜头的首帧。
每镜动作量服从实际模型时长；若动作放不下，规划阶段拆镜，不删台词、不任意提高秒数。


## 基础字段

- **scene_id**：`E2S{两位序号}` 格式（如 E2S01），按分镜顺序递增，不得用其他集号前缀。
- **duration_seconds**：从支持的秒数档位（5, 8, 10, 12）中按画面内容复杂度匹配合适时长（最长 12 秒），不强制默认值。再按台词口播长度设下界：先估算该场 utterances（台词 + 画外音）念完约需的秒数（口播语速约 5 字/秒），在上述档位里取**不低于**这个秒数的最接近档位；这是单向下界——画面 / 情绪留白可在此之上取更长档位，但台词永不把时长压到念不完的短档，utterances 为空（纯画面、无口播）的场景没有此下界、按画面自行取值；若口播估算已超过最长 12 秒，取最长档即可（不删减台词、不强行压进短档），保存时会另有提示。本集成片目标时长约 120 秒：据此决定本集的单元数与拆分粒度，让各单元时长合计向该目标靠拢。这是软目标、不是硬上限——内容不足以支撑目标时宁可少拆几个，不要靠注水 / 切碎凑满；内容确实需要更多篇幅时可以超出目标，不要为压进目标删减必要情节。
- **characters_in_scene** / **scenes** / **props**：从下列候选中列出此分镜实际出现的资产。
  - 候选 characters：[沈宁, 林砚, 沈明微, 萧承煜, 沈靖, 沈夫人, 沈家兄长, 青杏, 萧宁, 徐婉, 太后, 顾闻洲, 陆尚书, 王总管, 宁王, 裴砚, 谢柔嘉, 高进, 阿蘅]
  - 候选 scenes：[雨夜店门, 冷宫雪夜, 沈家闺房, 沈家院落, 凤仪宫, 寿安宫, 含露院, 朝堂议政殿, 北上粮道, 北境北风关, 清河仓, 御前暖阁, 承明殿万寿大典, 宫门雪地, 廊下炭炉]
  - 候选 props：[毒酒, 磨钝簪子, 绣燕旧衣, 金镯子, 海棠步摇, 凤印, 六宫账册, 粮契银票, 布老虎, 旧布记录纸, 北境军报, 军需封存原令, 兵符, 清河仓簿, 拟诏与密信底稿, 素金簪, 佩剑, 栗子炭炉]
  - 不要发明候选之外的名称；泛指群演（如「老人甲」「村民若干」）不登记为角色资产、不进 characters_in_scene。
- **scene_description**：改编后的视觉化描述：角色动作、神态、环境、光影氛围，适合画面呈现。以本分镜当下的单一时空落笔——原文的回忆、闪回、心理活动，改编为此刻可见的载体（人物神态、手中物件、环境痕迹）；这段描述是后续单帧分镜画面的内容来源。**台词 / 画外音不要写进这里**——口播统一落在 utterances。

## 逐字内容（内容真相源，定稿后原样保留、不再改写）

- **source_text**：逐字摘录本分镜对应的原文片段，尽量与原文一致、宁缺毋造（无把握可留空）。
- **utterances**：按口播出现顺序产出发声序列，台词（dialogue）的 speaker 必须出现在 characters_in_scene。叙述、心理独白等不靠画面演出的内容，可按剧情语境判断写为画外音（voiceover）——是否产出由你依语境创作判断，自然需要则产出。分镜无口播则留空。

每个分镜只能包含角色台词（dialogue）、旁白（voiceover）或无发声三种情况之一，不得在同一分镜混合 dialogue 与 voiceover；多名角色之间的对白可以同镜。若原文先后出现真实旁白与角色台词，必须按原顺序拆成独立分镜，保留全部发声内容与叙事含义，不可删词、改换说话人或把真实发声藏入画面描述来规避限制。舞台动作、场景说明、屏幕字、字幕、时间地点卡本身不是发声，写入 scene_description，仅当原文明示被朗读或实际说出时才进入 utterances；不要把动作叙述自动改成旁白。

每个分镜应为一个独立的视觉画面、可在指定时长内完成；避免在一个分镜内安排多个动作或画面切换。
