# 连续性提示词与视频联调

默认流程通过提示词描述同场景的固定布置、机位、人物起止状态和动作顺序。重写指定镜头时提供相邻镜头作为只读参考；宫格分批不改变剧情分段。旧剧本无需补填 continuity 才能继续生成。

视觉连续性复核是可选能力。后端环境变量 `ARCREEL_STRICT_MOTION_REVIEW=true` 才会启用 H3 的图片动作规划与生成后抽帧检查；默认关闭，不因模型对空间关系的判断阻止联调。启用时需要剧本文字模型支持图片输入，会发生额外文字/视觉模型调用。改变环境变量后需要重启后端。

开启后的报告保存在项目 `continuity/` 目录。输入图片、剧本参考、时长或比例变化会改变规划缓存键。生成后均匀抽取最多 12 帧进行检查；结果不等同于完整视频、对白、口型或声音验收。未通过时付费视频保留在历史版本，不自动选择为当前视频。关闭检查后，已标记不允许恢复的历史结果仍保留原审核标记。

## 主流程验收顺序

1. 确认云端连接、模型可用状态和实际排队任务。
2. 使用已有正式首帧，验证人物对白或独立旁白、字幕、视频预览和成片导出。旁白不能替代人物对白。
3. 核对文件的实际像素尺寸、帧率、时长和音轨。画布尺寸或导出设置不能代替实际文件检查。
4. 对一段样片比较较高原生分辨率或超分处理结果，记录原生尺寸、后处理方式、最终尺寸和耗时。竖屏高清成片的目标为 1080×1920；当前 576×1024 的 H3 档位不代表这一目标已经通过。
5. 样片达到要求后再扩展到整集。布景与姿态细节按成片反馈迭代提示词。

生成提示词可以降低空间跳变，但不保证模型严格遵循。默认联调不新增额外逐格审批流程。
